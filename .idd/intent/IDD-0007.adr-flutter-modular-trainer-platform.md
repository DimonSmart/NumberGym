# IDD-0007.adr-flutter-modular-trainer-platform

## Status

Accepted

## Context

The product family contains multiple language-trainer applications and must
remain cross-platform while allowing each application to own its branding and
content.

## Decision

All trainer applications use Flutter as the cross-platform application
foundation. The product is organized as independently branded applications,
their content packages, and a shared trainer platform. New trainer applications
follow the same modular boundary.

## Alternatives Considered

- A separate platform-specific implementation for each trainer application.
- A single application that combines all trainer identities and content.
- App-specific copies of the training platform.

## Consequences

The shared trainer platform remains independent of any individual app's branding
and content. Applications and their content packages can evolve independently
while preserving shared trainer behavior. Specific third-party libraries remain
replaceable implementation choices.

## Supersedes

None.
