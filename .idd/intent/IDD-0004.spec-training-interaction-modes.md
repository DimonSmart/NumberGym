# IDD-0004.spec-training-interaction-modes

## Intent

Trainer applications use a common set of interaction modes so that different
content areas can exercise speaking, recognition, reading, and listening skills
consistently.

## Related Specifications

- IDD-0001
- IDD-0002

## Behavior

- Pronunciation exercises ask the learner to speak an expected answer and
  evaluate the recognised response.
- Prompt-to-answer choice exercises show a prompt and ask the learner to select
  its answer.
- Answer-to-prompt choice exercises show an answer and ask the learner to
  select its corresponding prompt.
- Listening-and-choice exercises play an answer and ask the learner to select
  its corresponding prompt.
- Each content family declares the modes it supports; unavailable or
  incompatible modes are never silently substituted.
- An application may add a content-specific mode only when its availability,
  progress effects, and user feedback are explicit.

## Durable Architecture And Constraints

The shared trainer platform owns the interaction semantics. Content packages
declare which modes their exercise families support.

## Non-Goals

- Requiring every exercise family to support every interaction mode.
- Treating a premium analysis feature as a normal learning-progress attempt
  unless a future specification explicitly changes that rule.

## Acceptance Criteria

- A scheduled exercise uses a mode supported by its content family.
- A learner receives an actionable reason when a required capability is not
  available.
- Choice and listening exercises preserve the intended prompt-to-answer or
  answer-to-prompt direction.

## Verification

- Automated coverage establishes mode compatibility for each content family.
- Automated coverage establishes availability handling and interaction
  direction for every shared mode.
